## Как читать формулировки гипотез

У каждой гипотезы — **два слоя**:

1. **Простыми словами.** То, что произносится вслух и понимается с первого раза.
   Здесь же сказано, при каком исходе гипотеза не подтвердится.
2. **Формально.** Та же гипотеза с метрикой, формулой, порогом и выборкой.

Второй слой обязателен по критериям НИР, первый — чтобы гипотезу поняли. Ни один
не заменяет другой.

## Условные обозначения

| Пометка | Значение |
|---|---|
| `[факт]` | проверено в коде, в базе или замерено на продакшне |
| `[допущение]` | принято как рабочее предположение, требует подтверждения |
| `[надо уточнить у команды]` | нужен ответ участников, без него артефакт неполон |
| `[надо проверить экспериментом]` | ответ даст только эксперимент |
| `[проверено поиском]` | источник найден и сверен |
| `[проверить]` | источник назван по памяти, требует сверки |
| `X` | цифры нет; рядом сказано, откуда её взять |
