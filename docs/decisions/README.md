# boks Architecture Decisions

Use this folder for decisions that affect future rewrites or product direction.

Create a new file when a change affects:

- data ownership
- recommendation assignment
- authentication and roles
- publishing and moderation flow
- metrics model
- hosting strategy
- large directory structure
- agent-readable documentation and onboarding workflow

Template:

```md
# ADR YYYY-MM-DD: Title

## Context

What changed or what pressure appeared?

## Decision

What are we doing?

## Consequences

What becomes easier, harder, or explicitly deferred?
```
